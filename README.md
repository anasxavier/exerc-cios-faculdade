# 📚 Exercícios de Programação - Faculdade

Este repositório reúne os exercícios práticos desenvolvidos durante as aulas da faculdade, englobando conceitos de lógica de programação e desenvolvimento web.

## 📁 Estrutura do Projeto

### 🐍 `/python`
- **Cálculo de Média:** Cálculo com notas ponderadas e subprogramas em funções.
- **Calculadora de IMC:** Avaliação de faixas de peso com estruturas condicionais `elif/else`.
- **Reajuste Salarial:** Aplicação de regras de negócio para aumento de salário baseado em faixas.

### ⚡ `/c`
- **Cadastro de Produtos:** Entrada de dados com `fgets` e saída formatada.
- **Posto de Combustível:** Cálculo de descontos usando `switch/case` e condicionais encadeadas.
- **Jogo de Adivinhação:** Laço de repetição `while` com sistema de palpites e dicas.
- **Cálculos e Repetições:** Exemplos práticos de `do-while`, `for`, classificação de idades e cálculo de IMC.

### 🌐 `/html-css`
- **Estrutura Semântica:** Uso das tags `<header>`, `<main>`, `<article>` e `<footer>`.
- **Tabelas e Listas:** Formatação de dados estruturados, listas ordenadas e não ordenadas.
- **Estilização CSS:** Arquivo CSS externo com regras de seletores, classes e espaçamentos.

## 🛠️ Tecnologias Utilizadas
- **Python**
- **Linguagem C**
- **HTML5 & CSS**
